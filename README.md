## 🌟 Возможности

### 📊 Сбор данных (5 типов выдачи)
- **🌐 Веб-поиск** — органическая выдача: позиция, заголовок, чистый URL, домен, сниппет.
- **🎯 Проверка позиций (Rank Tracker)** — автоматическое определение позиции целевого домена по списку ключевых слов (до 100-й позиции) с моментальной остановкой при нахождении сайта и переходом к следующему запросу.
- **📑 Количество страниц (site:)** — автоматическая проверка числа проиндексированных страниц для списка доменов (по 1 запросу на домен с оператором `site:`).
- **🖼 Картинки (Google Images)** — страницы-источники на которых ссылки на картинки а не сами ссылки на картинки, домены.
- **🎬 Видео (Google Videos)** — ролики YouTube/Rutube/Vimeo/TikTok, каналы авторов, длительность, описания.
- **Глубина**: от Топ-10 до Топ-100 по каждому ключевому слову.
- **Фильтр по времени**: за час, 24 часа, неделю, месяц, год или за всё время.
- **Гео-локализация**: 15 регионов (США, Россия, Казахстан, Германия и др.) и 10 языков интерфейса.
- **Блоки PAA** (People Also Ask) — быстрое извлечение вопросов.

### ⚖️ Сравнение результатов (SERP Diff)
- Сравнение любых двух запусков «до/после», «24 часа/год» и т.д.
- Динамика по каждому сайту: **▲ рост**, **▼ падение**, **= без изменений**, **✨ новые**, **❌ выпавшие**.
- Сводные карточки KPI: всего/рост/падение/новые/выпавшие.
- Быстрые фильтры и полнотекстовый поиск по таблице.
- Экспорт отчёта сравнения в Excel/CSV/JSON.

### 📸 Снимки (Snapshots)
- Автосохранение каждого запуска в историю с фиксацией периода, региона и даты.
- Ручное сохранение с пользовательским названием («За 24 часа», «После апдейта»).
- Менеджер снимков: просмотр, загрузка обратно в таблицу, удаление, очистка.

### ⚡️ Производительность и защита
- **Многопоточность**: 1–5 потоков с настраиваемой задержкой (Smart Jitter).
- **Автодетектор капчи**: при `google.com/sorry` парсер ставит паузу, показывает баннер и открывает страницу проверки в 1 клик.
- **Сохранение состояния**: настройки и история снимков в `chrome.storage.local`.

### 📁 Экспорт и быстрое копирование
- **Excel (.xlsx)**: оптимальная ширина колонок, закреплённая шапка, автофильтр.
- **CSV** с UTF-8 BOM (корректная кириллица в Microsoft Excel).
- **JSON** для интеграций и API.
- **Скачать ссылки (.txt)**: чистый список URL одним файлом.
- **Копировать ссылки / сниппеты** в буфер обмена в 1 клик.

### 🎨 Интерфейс
- Тёмная Glassmorphism-тема: `#0f172a`, размытые карточки, акценты синий/изумрудный.
- Drag-and-Drop файлов `.txt` / `.csv` для загрузки базы ключевых слов.
- Статистика реального времени: счётчики запросов, ссылок, ошибок, таймер, прогресс-бар.

## 🛠 Установка в Google Chrome
 
1. Откройте `chrome://extensions/`.
2. Включите тумблер **«Режим разработчика»** (правый верхний угол).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `GoogleParserChrome`.
5. Закрепите значок расширения на панели инструментов.

> [!IMPORTANT]
> Запускать расширение можно как во всплывающем окне (клик по иконке), так и в отдельной вкладке на весь экран (кнопка ↗ в шапке).

## 📖 Примеры работы

### Пример 1. Базовый сбор топ-100
1. Вставьте ключевые слова в поле (по одному на строку) или перетащите `.txt`.
2. Поставьте **«Глубина»** = 10 страниц, **«Потоков»** = 2, **«Задержка»** = 1.5–3.0 сек (рекомендуется).
3. Нажмите **«Старт парсинга»** → прогресс-бар и таблица обновятся в реальном времени.
4. Когда сбор завершён, нажмите **«Excel (.xlsx)»** — готовый отчёт скачается в 1 клик.

### Пример 2. Сравнение «до и после апдейта Google»
1. Спарсите выдачу **сегодня**, нажмите **«Сохранить снимок»**, назовите «Сегодня».
2. Спарсите ту же базу **через неделю**, сохраните снимок «Через неделю».
3. Перейдите на вкладку **«Сравнение результатов (Diff)»**.
4. Выберите Снимок А = «Сегодня», Снимок B = «Через неделю» → **«Сравнить результаты»**.
5. Видите, кто вырос (`▲ +N`), кто упал (`▼ -N`), кто появился (`✨ NEW`) и кто пропал (`❌ LOST`).
6. Нажмите **«Excel (.xlsx)»** в панели Diff — экспорт с колонками дельты и статуса.

### Пример 3. Сбор картинок и видео
- В **«Тип выдачи»** выберите Картинки или Видео → нажмите «Старт».
- В отчёт попадут прямые ссылки на медиафайлы, платформы, каналы и описания.

## 📝 Журнал изменений (Changelog)

### Версия 1.8.33
- 🔢 **Исправление сквозного подсчета позиций во всех парсерах**: Устранена ошибка, из-за которой при переходе на последующие страницы выдачи (`start=10`, `start=20`, ..., `start=80`) номер позиции мог считываться как порядковый номер на текущей странице (1..10) вместо абсолютной позиции в выдаче Google.
- 🎯 **Точный расчет позиций в Rank Tracker и веб-парсинге**: Теперь во всех режимах позиция высчитывается строго по формуле `basePosition + index + 1` (например, 4-я строка на 9-й странице `start=80` получает точную позицию **84**).
- 🔄 **Двусторонняя синхронизация `basePosition`**: Передача смещения `basePosition` из фонового воркера в `content.js` и автоматическое определение из параметра `start` в URL.

### Версия 1.8.32
- 🎯 **Новый режим: «Проверка позиций сайта (Rank Tracker)»**: Добавлен специализированный режим автоматического определения позиций заданного сайта в поисковой выдаче Google по списку ключевых слов.
- ⚡️ **Мгновенная ранняя остановка (Early Stop)**: Проверка позиций осуществляется до 100-й позиции (10 страниц выдачи). Как только целевой домен обнаружен на очередной странице выдачи (например, на 4-й позиции), парсер немедленно фиксирует позицию, удаляет оставшиеся страницы этого запроса из очереди задач и моментально переходит к следующему запросу.
- 📊 **Формат отчета Домен | Запрос | Позиция**: В отчётах Excel (.xlsx), CSV, JSON и таблице предпросмотра формируется четкая структура с приоритетными колонками Домен, Запрос, Позиция, URL, Title и Сниппет. Если сайт не найден до 100-й позиции, выставляется понятный статус `>100`.
- 🌐 **Гибкость задания доменов**: Поддерживается как указание глобального целевого домена в отдельном поле настроек (применимо ко всем запросам), так и индивидуальное задание домена для каждого ключа в формате `запрос;домен` или `запрос | домен`.

### Версия 1.8.31
- 🎯 **Устранение фантомных сниппетов и привязки чужих доменов**: Исправлена проблема, из-за которой при быстрой навигации во вкладке или пустой выдаче Google домены могли считывать DOM предыдущей страницы или брать сниппеты из блока рекомендаций Google.
- ⏳ **Синхронизация запроса (Query Verification)**: Добавлена строгая проверка соответствия поискового запроса в URL и DOM перед извлечением данных (`waitForTabReady` + проверка в `content.js`), исключающая чтение устаревшего DOM при повторном использовании вкладок.
- 🛡️ **Строгая изоляция в режиме `site:`**: Для доменов с 0 страниц в индексе теперь гарантированно выставляется 0 страниц, собственный URL домена и очищенный сниппет без подмешивания сторонних сайтов.

### Версия 1.8.30
- 🛡️ **Надежное возобновление после капчи Google**: Исправлена проблема, из-за которой после прохождения капчи парсинг не стартовал при нажатии «Продолжить». Очередь задач (`queue`) и прогресс по запросам теперь полностью сохраняются в `chrome.storage.local`, предотвращая потерю состояния при засыпании Background Service Worker (MV3).
- 🔄 **Автоматическое распознавание решения капчи**: Добавлен отслеживатель вкладок (`tabs.onUpdated`): когда пользователь решает капчу и Google делает редирект на результаты поиска, расширение автоматически возобновляет парсинг.
- 💓 **Heartbeat механизм в Service Worker**: Добавлена поддержка активности Service Worker на время ожидания решения капчи и выполнения фоновых задач.
